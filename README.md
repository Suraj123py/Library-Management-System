   # Library Management System

   Console-based library app built with Python and MySQL.

   ## Features
   - Add, remove, list and search books
   - Register and list members
   - Issue and return books with 14-day due dates
   - Automatic fine calculation for late returns

   ## Tech
   Python 3, MySQL (mysql-connector-python)

   ## Run
   1. Start MySQL (for example with XAMPP)
   2. `pip install mysql-connector-python`
   3. `python library.py`
